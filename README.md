# Belém Rios - Sistema Interno 🚍

Sistema desenvolvido em colaboração para a empresa **Belém Rios LTDA**, com o objetivo de auxiliar em processos internos e apoiar atividades relacionadas à gestão de informações da empresa.

## 📌 Contexto do Projeto

Este projeto foi desenvolvido em conjunto com meu gestor durante minha atuação na empresa **Belém Rios Transporte LTDA**, com foco em criar soluções tecnológicas para otimizar processos internos.

A aplicação foi utilizada como ferramenta de apoio em atividades operacionais da empresa.

## 🚀 Tecnologias utilizadas

- C#
- .NET
- SQL Server
- HTML
- CSS
- JavaScript

## ⚙️ Funcionalidades

- Sistema interno para gestão de informações
- Manipulação e armazenamento de dados
- Interface web para interação com o sistema
- Organização de dados utilizados nos processos da empresa
